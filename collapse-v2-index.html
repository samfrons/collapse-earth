Collapse Earth — internal review

Four redesigns of one data layer.

Same tipping-point data, funding ledger and hypothesis engine, rendered four different ways. Built to compare visual language and information architecture before committing to one direction for the public site.

/ still serves the current production site (collapse-tech.html) — nothing below is deployed.

Chosen lead direction

Core Sample — deep time, material

Scroll as drill core: page strata shift bone → ochre → rust → carbon, an engraved line-art globe, progressive disclosure so depth arrives on demand rather than all at once.

collapse-v2-coresample.html

Deep Field — solemn luminosity

A dark-ocean globe of bioluminescent nodes sized by uncertainty, illuminated specimen-label cards for each hypothesis.

collapse-v2-deepfield.html

Signal / Noise — observatory

Instrument-panel chrome over a satellite hero: calibrated readouts, reticle overlays, hypotheses logged as numbered entries.

collapse-v2-signal.html

Overgrowth — grave problem, living response

A scroll-driven desaturation arc — near-grayscale thresholds giving way to full verdant color by the time hypotheses appear.

collapse-v2-overgrowth.html

All four consume the same shared data layer, collapse-data.v2.js (updated 2026-07-30) — every threshold, funding figure and hypothesis is identical across variants; only the rendering differs.
